# Система типов

ELang — статически типизированный язык. Все переменные и функции обязаны иметь явные типы.

```elang
let x: i64 = 42           // ПРАВИЛЬНО
let x = 42                // ОШИБКА: expected ':'
fn add(a: i64, b: i64) -> i64 { a + b }   // ПРАВИЛЬНО
fn add(a, b) { a + b }                      // ОШИБКА: expected ':'
```

## Целочисленные типы

| Тип | Размер | Диапазон |
|-----|--------|----------|
| `i8` | 1 байт | -128 .. 127 |
| `i16` | 2 байта | -32768 .. 32767 |
| `i32` | 4 байта | -2^31 .. 2^31-1 |
| `i64` | 8 байт | -2^63 .. 2^63-1 |
| `u8` | 1 байт | 0 .. 255 |
| `u16` | 2 байта | 0 .. 65535 |
| `u32` | 4 байта | 0 .. 2^32-1 |
| `u64` | 8 байт | 0 .. 2^64-1 |

Все целочисленные типы неявно совместимы друг с другом при арифметических операциях.

## Типы с плавающей точкой

| Тип | Размер | Описание |
|-----|--------|----------|
| `f32` | 4 байта | IEEE 754 single |
| `f64` | 8 байт | IEEE 754 double |

Float операции выполняются через SSE2 (`addsd`, `subsd`, `mulsd`, `divsd`). Значения хранятся как IEEE 754 bits в стеке.

## Другие типы

| Тип | Описание |
|-----|----------|
| `bool` | Логический: `true` / `false` |
| `char` | Символ (1 байт) |
| `string` | Строка (указатель на null-terminated) |
| `void` | Отсутствие значения |
| `*T` | Указатель на T |
| `[T]` | Массив элементов типа T (heap-allocated) |
| `Result<T, E>` | Результат: `Ok(T)` или `Err(E)` |
| `(T1, T2, ...)` | Кортеж |

## Literals

### Целочисленные

```elang
let dec: i64 = 42          // десятичный
let hex: i64 = 0xFF        // шестнадцатеричный (= 255)
let oct: i64 = 0o77        // восьмеричный (= 63)
let bin: i64 = 0b1010      // двоичный (= 10)
let sep: i64 = 1_000_000   // разделитель тысяч (= 1000000)
```

### С плавающей точкой

```elang
let pi: f64 = 3.14159
let small: f64 = 0.001
```

### Строки

```elang
let s: string = "Hello, ELang!\n"
let esc: string = "tab\there"     // \t, \n, \r, \0, \\, \", \'
```

### Символы

```elang
let c: char = 'A'
let nl: char = '\n'
```

### Логические

```elang
let t: bool = true
let f: bool = false
```

### Указатели

```elang
let p: *i64 = ptr   // указатель на i64
```

## Result\<T, E\>

Типобезопасная обработка ошибок. Кодируется через младший бит: `Ok(val)` = `val << 1 | 0`, `Err(val)` = `val << 1 | 1`.

```elang
fn divide(a: i64, b: i64) -> Result<i64, i64> {
    if b == 0 { return Err(0) }
    return Ok(a / b)
}
```

Подробнее: [Обработка ошибок](error-handling.md).

## Массивы

Heap-allocated, bounds-checked. Литералы: `[1, 2, 3]`.

```elang
let arr: [i64] = [10, 20, 30]         // динамический массив
let fixed: [i64; 3] = [10, 20, 30]    // фиксированный массив из 3 элементов
let nested: [[i64; 3]; 2] = [[1,2,3], [4,5,6]]  // 2D массив

let first: i64 = arr[0]   // 10
let length: i64 = arr.len // 3

// Функции принимают массивы как параметры
fn sum(items: [i64]) -> i64 {
    let s: i64 = 0
    let i: i64 = 0
    while i < items.len {
        s = s + items[i]
        i = i + 1
    }
    return s
}
```

### Layout в памяти

```
[ptr - 32] = elem_size (qword) — байт на элемент (1, 2, 4 или 8)
[ptr - 24] = refcount  (qword)
[ptr - 16] = capacity  (qword)
[ptr - 8]  = length    (qword)
[ptr + 0]  = element[0]
[ptr + elem_size] = element[1]
...
```

Подробнее: [Стандартная библиотека](standard-library.md).

## Массивы vs Кортежи

| Особенность | `[T]` (массив) | `(T1, T2)` (кортеж) |
|-------------|----------------|---------------------|
| Размер | Динамический | Фиксированный |
| Память | Heap | Stack |
| Доступ по индексу | `arr[i]` | `t.0`, `t.1` (нет) |
| Длина | `arr.len` | Фиксирована |
| map/filter/reduce | Да | Нет |
